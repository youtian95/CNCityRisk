# 汶川地震房屋倒塌率分布图数据提取工具

本项目用于从汶川地震房屋倒塌率分布图中提取空间数据，并将像素坐标转换为实际的经纬度坐标，为城市韧性评估研究提供基础数据支持。

## 项目概述

该工具集包含三个主要功能模块：
1. **数据提取工具** (`simple_extractor.py`) - 从地图图像中交互式提取散点数据
2. **坐标转换工具** (`convert_coord.py`) - 将像素坐标转换为真实地理坐标
3. **数据可视化工具** (`plot_results.py`) - 生成基于地理坐标的专业散点分布图

## 文件说明

### 工具文件
- `simple_extractor.py` - 简化版数据提取工具，用于在地图上标记数据点
- `convert_coord.py` - 坐标转换工具，支持像素坐标到经纬度的转换
- `plot_results.py` - 数据可视化工具，生成带地理坐标的散点分布图
- `README.md` - 项目说明文档

### 数据文件
- `data_20250904_150159.csv` - 提取的像素坐标数据样例
- `calibration.json` - 坐标校准参数文件（运行后自动生成）

### 地图图像
- `101个乡镇倒塌率分布.jpg` - 汶川地震101个乡镇房屋倒塌率分布图
- `汶川地震重灾区房倒率插值图与地震烈度图.jpg` - 重灾区房屋倒塌率与烈度对比图

## 使用步骤

### 第一步：数据提取

1. **启动数据提取工具**
   ```bash
   python simple_extractor.py
   ```

2. **选择地图图像**
   - 程序会显示当前目录下的所有图片文件
   - 输入数字选择要分析的地图图像

3. **交互式数据标记**
   - **左键点击**：在地图上标记数据点
   - **右键点击**：删除最近的标记点
   - **数字键1-10**：切换房屋倒塌率类别
   - **S键**：保存数据
   - **C键**：清除所有标记
   - **Z键**：撤销最后一个标记

4. **保存数据**
   - 数据自动保存为CSV格式
   - 文件名格式：`data_YYYYMMDD_HHMMSS.csv`

### 第二步：坐标转换

1. **启动坐标转换工具**
   ```bash
   python convert_coord.py
   ```

2. **选择地图图像**
   - 选择与数据提取步骤相同的地图图像

3. **坐标系统校准**
   
   **首次使用或重新校准：**
   - 在弹出的地图窗口中点击已知地理位置的点
   - 在右侧输入框中填写该点的信息：
     - 地点名称（如：汶川县城）
     - 经度（如：103.5892）
     - 纬度（如：31.4759）
   - 点击"确认添加"保存控制点
   - 重复添加至少3个控制点（推荐4-6个）
   - 点击"完成校准"

   **使用已保存的校准：**
   - 如果存在`calibration.json`文件，可选择使用之前的校准参数

4. **控制点建议**
   - 县城中心、乡镇中心
   - 主要河流交汇点
   - 明显的山峰地标
   - 公路交叉口

5. **数据转换**
   - 选择要转换的CSV数据文件
   - 程序自动进行坐标转换
   - 输出文件格式：`原文件名_with_coords.csv`

### 第三步：数据可视化

1. **启动绘图工具**
   ```bash
   python plot_results.py
   ```

2. **功能特性**
   - 自动加载带有坐标的CSV数据文件
   - 绘制基于四川省地图的散点分布图
   - 显示县区轮廓线作为地理参考
   - 根据倒塌率自动调整圆圈大小（倒塌率越高，圆圈越大）
   - 使用颜色编码区分不同倒塌率等级

3. **输出文件**
   - `wenchuan_earthquake_collapse_rate_map.png` - 高分辨率PNG图像
   - `wenchuan_earthquake_collapse_rate_map.pdf` - 矢量PDF文件

## 输出数据格式

### 原始数据 (simple_extractor.py 输出)
```csv
id,x,y,pixel_color,assigned_class,class_name,timestamp
1,279.03,117.09,"(55, 166, 2)",2,10-20%,2025-09-04T15:01:54.983657
```

### 转换后数据 (convert_coord.py 输出)
```csv
id,x,y,pixel_color,assigned_class,class_name,timestamp,longitude,latitude
1,279.03,117.09,"(55, 166, 2)",2,10-20%,2025-09-04T15:01:54.983657,103.589234,31.475912
```

### 字段说明
- `id`: 数据点编号
- `x, y`: 像素坐标
- `pixel_color`: 该点的RGB颜色值
- `assigned_class`: 分配的倒塌率类别(1-10)
- `class_name`: 倒塌率范围描述
- `timestamp`: 数据标记时间
- `longitude, latitude`: 转换后的经纬度坐标
